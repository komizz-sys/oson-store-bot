# SMS Relay — пересыльщик банковских уведомлений

Третий сервис рядом с ботом и магазином. Нужен ровно для одного: уведомления
о поступлении денег приходят **от бота банка**, а Telegram не доставляет
сообщения одного бота другому — значит, магазин-бот их не видит и никогда не
увидит. Этот сервис заходит в Telegram **твоим аккаунтом** (обычным
пользователем), читает чат с ботом банка и пересылает текст магазин-боту
обычным сообщением. Такое сообщение бот уже видит и разбирает.

Слушает ровно один чат — тот, что ты выберешь кнопкой на его странице. Всё
остальное игнорирует, переписку не хранит, никуда больше не пишет.

## Что делаешь ты (2 минуты, с телефона)

1. Открываешь адрес сервиса со ссылкой-паролем (я её дам).
2. Вводишь номер аккаунта, куда приходят уведомления банка.
3. Вводишь код — он придёт **сообщением в Telegram**, не по SMS.
   Если включён облачный пароль (2FA) — вводишь и его.
4. В списке чатов находишь бота банка и жмёшь «Слушать».
5. Жмёшь «Отправить тест» — проверяем, что цепочка работает.

Всё. Вход сохраняется на диске сервиса сам, копировать ничего не нужно.

## Безопасность

- Вход в аккаунт (файл сессии) лежит **только на диске этого сервиса**. Он не
  показывается на странице, не пишется в логи и не хранится в переменных.
- Страница настройки закрыта паролем `RELAY_ADMIN_TOKEN` — без него открыть
  её нельзя.
- Сервис читает **один** выбранный чат. Не рассылает ничего от твоего имени,
  не отвечает никому, не сохраняет переписку.
- Никогда не отдавай доступ к аккаунту сторонним «ботам-пересыльщикам» из
  поиска: вместе с уведомлениями банка они получают всю переписку.
- Отключить в любой момент: Telegram → Настройки → Устройства → завершить
  сеанс «Telethon». После этого сервис перестанет читать что-либо.

## Переменные (их выставляю я при настройке)

| Переменная | Что это |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | ключи с my.telegram.org (аккаунта-пересыльщика) |
| `RELAY_ADMIN_TOKEN` | пароль к странице настройки |
| `TARGET_CHAT` | `@username` магазин-бота, кому пересылать |
| `SESSION_DIR` | папка на диске сервиса, где хранится вход (`/data`) |
| `SOURCE_CHAT` | необязательно: чат-источник, если задавать не кнопкой |

## Если что-то не работает

| Симптом | Причина |
|---|---|
| «Доступ закрыт» | в адресе нет или неверный `?token=` |
| «Нет ключей Telegram» | не заданы `TG_API_ID` / `TG_API_HASH` |
| Тест не доходит до бота | с аккаунта-пересыльщика не нажат `/start` у магазин-бота |
| Уведомления не пересылаются | не выбран чат-источник (кнопка «Слушать») |
| Дошло, но заказ не подтвердился | смотри логи бота по метке `[SMS]` — там видно разбор суммы |
| Просит вход заново после передеплоя | к сервису не подключён диск (том) |

`/health` отдаёт статус в JSON — живой ли сервис, вошли ли, что слушаем.
