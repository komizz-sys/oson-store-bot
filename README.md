# Telegram-бот: продажа Stars, Premium, аренда NFT-подарков (цены в UZS)

## Что умеет
- ⭐ Продажа Telegram Stars — 22 пакета, цены пересчитаны из Fragment ($ × 1.2 × курс UZS)
- 💎 Продажа Telegram Premium — 1/3/6/12 мес (12 мес двумя способами)
- 🖼 Аренда NFT-подарков — **живой список с marketapp.org** через официальный API
- Оплата: пользователь переводит на карту вручную → присылает чек →
  админ подтверждает кнопкой в боте
- **Автовыполнение через API MarketApp** (см. ниже) — для Stars/Premium/аренды
  бот сам готовит транзакцию, админу остаётся тапнуть ссылку и подтвердить
  в своём кошельке (Tonkeeper и т.п.)

## Как работает автовыполнение

У MarketApp (marketapp.org) есть официальный API (`api.marketapp.org`), который
умеет и покупать Stars/Premium через Fragment, и оформлять аренду NFT-подарков.
Ключ уже вписан в `.env` (`MARKETAPP_API_KEY`).

Процесс для каждого заказа после подтверждения оплаты:
1. Бот вызывает нужный метод API (`buy_stars` / `buy_premium` / `rent_pay`)
2. API возвращает готовую TON-транзакцию
3. Бот присылает админу ссылку — она открывает кошелёк с уже заполненной
   транзакцией, остаётся только подтвердить
4. Админ подтверждает → проверяет, что всё доставлено → жмёт "Заказ выполнен"

**Seed-фраза кошелька нигде не хранится** — админ подтверждает каждую
транзакцию сам в своём кошельке, бот только готовит данные.

⚠️ **Для аренды**: платить нужно ТЕМ ЖЕ кошельком, которым был сгенерирован
API-токен на marketapp.org (тот, что показан как `UQC3...cz18` в личном кабинете).

⚠️ **Ограничение API**: Premium через Fragment продаётся только на 3/6/12 месяцев.
Тариф "1 месяц" всегда уходит админу на полностью ручное выполнение — бот
пришлёт уведомление вместо ссылки на оплату.

## Установка

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

`.env` уже заполнен (токен бота, твой admin ID, ключ MarketApp). Если нужно
поменять реквизиты карты для приёма оплаты — впиши `PAYMENT_CARD_NUMBER` и
`PAYMENT_CARD_HOLDER` в `.env`.

## Цены

- `data/prices.json` — Stars и Premium (готовые цены в сумах, правь вручную)
- Аренда NFT теперь **не берётся из JSON** — список гифтов и их цены грузятся
  живьём с marketapp.org при каждом открытии раздела "Аренда NFT" в боте.
  Формула наценки (20% + комиссия сети) — в `.env`:
  `RENT_MARKUP`, `TON_GRAM_RATE_UZS`, `RENT_FEE_GRAM`, `RENT_FEE_REFUND_PERCENT`

## Запуск

```bash
python bot.py
```

## Мини-апп (веб-версия магазина внутри Telegram)

В проекте два процесса:
- `bot.py` — сам бот (Worker-сервис на Railway)
- `webapp_server.py` — отдаёт мини-апп: каталог + статику (Web-сервис на Railway)

### Деплой мини-аппа

1. У тебя уже есть Web-сервис на Railway — подключи его к тому же GitHub-репозиторию
2. В настройках этого Web-сервиса задай **Start Command**:
   ```
   uvicorn webapp_server:app --host 0.0.0.0 --port $PORT
   ```
3. Скопируй туда те же переменные окружения, что и в Worker-сервисе (`BOT_TOKEN`,
   `MARKETAPP_API_KEY`, `STAR_UNIT_PRICE_UZS`, `RENT_MARKUP`, `TON_GRAM_RATE_UZS`,
   `RENT_FEE_GRAM`, `RENT_FEE_REFUND_PERCENT`) — Railway → Variables → можно
   скопировать из другого сервиса через "Reference"
4. После деплоя Railway даст домен вида `https://xxxx.up.railway.app` —
   **Settings → Networking → Generate Domain**, если ещё не сгенерирован
5. Скопируй этот домен и добавь его в переменные **Worker**-сервиса (бота):
   `WEBAPP_URL=https://xxxx.up.railway.app`
6. Перезапусти Worker — в главном меню бота появится кнопка "🛍 Открыть магазин",
   а в меню чата (кнопка рядом со скрепкой) — быстрый доступ к магазину

### Как это работает

Мини-апп — это просто красивый каталог. Сам заказ (ввод получателя, подтверждение,
оплата) происходит в чате с ботом: при выборе товара мини-апп закрывается и
передаёт данные боту (`Telegram.WebApp.sendData`), а дальше работает тот же
проверенный сценарий, что и при обычном заказе через кнопки.

- Команды админа для редактирования цен звёзд/премиум прямо из бота
- Рассылка (broadcast) всем пользователям
- Автоматическая проверка on-chain подтверждения транзакции (сейчас — вручную
  через кнопку "Заказ выполнен")
- Интеграция реального эквайринга Click/Payme вместо ручного чека
